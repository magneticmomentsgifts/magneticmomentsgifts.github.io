# Magnetic Moments & Gifts website

A simple static website built with HTML, CSS and JavaScript.

## Run locally

Option 1:
Double-click `index.html`.

Option 2 (recommended if Python is installed):
```bash
python -m http.server 5500
```

Then open:
http://localhost:5500

## Main files
- `index.html` — page content
- `styles.css` — design and mobile responsiveness
- `script.js` — mobile menu and current year
